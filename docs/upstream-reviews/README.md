# Upstream Reviews

Dated compatibility reviews of the source projects that inspired pi-hybrid-memory.

Each review compares current upstream revisions against the exact baselines recorded in
[`../../REFERENCE_COMMITS.md`](../../REFERENCE_COMMITS.md), then classifies changes by compatibility
risk and recommendation. Reviews are research records; they do not imply that listed changes were
merged.
